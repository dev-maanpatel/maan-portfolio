# Maan Patel React Portfolio

Modern React portfolio with live particles background, sticky header, light/dark theme, project gallery, blog detail pages, resume section and CV download.

## Run
```bash
npm install
npm run dev
```

## Contact form email
The form is ready for EmailJS. Add your EmailJS values in `.env` using `.env.example` and messages will send to `dev.maanpatel1@gmail.com`.
Without EmailJS keys, the form opens the user email app with your Gmail address filled.
